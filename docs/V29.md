# V29: strict 3D baseline and residual interface

This milestone is a classical controller, not a trained V29 AI model. The
reference vehicle still uses declared simulation parameters. Hardware transfer
and a 99% full-envelope claim have not been established.

## Run

Use an environment containing MuJoCo, Gymnasium, NumPy and Stable-Baselines3.
Local verification used MuJoCo 4.0.1 and Gymnasium 1.4.0. The repository's
existing sensor wrappers and report function are reused.

```powershell
python -m unittest discover -s tests -v
python src/evaluate_v29.py --episodes 200 --out logs/v29_clean.csv
python src/evaluate_v29.py --episodes 200 --delay 2 --out logs/v29_delay.csv
python src/evaluate_v29.py --episodes 200 --difficulty 1 --delay 2 --noise --out logs/v29_full.csv
python src/evaluate_v29.py --episodes 1 --seed 30004 --difficulty 1 --delay 2 --noise --traces logs/v29_traces
```

The Colab equivalent is `notebooks/v29_baseline_colab.ipynb`. Its GitHub clone
requires these source files to be committed and pushed first. No GPU is required
for the classical audit. Do not load V28 or V27 checkpoints into this controller.

## Interfaces

- `MissionEnv`: V29 success contract, absorbing mission deadline, substep impact
  and hull checks. Existing V28 environment retains its default behavior.
- `mission_sensors`: delay and independently selectable, episode-seeded noise.
- `LandingController(observation)`: receives only the 16 sensor values; accesses
  no true mass, wind or simulator kinematics. Nominal vehicle constants remain
  design inputs. Reset its state at each mission.
- `ResidualLandingEnv`: wrap after sensors and before any frame stacking. Zero
  residual exactly reproduces the baseline. Observations include baseline action,
  phase and controller integrals. Residual authority defaults to normalized
  `(0.10, 0.15, 0.15, 0.10)` and all applied controls are bounded.

## Interpretation

The clean gate requires at least 200 episodes and >=99% precise, with all failures
counted. A small clean test is a development gate, not final evidence of 99%
under all disturbances. Seeds 30000 onward here are development seeds. Reserve
an independent frozen final audit and include confidence intervals.

Raw CSVs and their JSON sidecars live in ignored `logs/`. The compact measured
result record is `docs/v29_baseline_results.json`. Failures include final position,
tilt, speed, impact components, minimum altitude, saturation and phase durations.

## Next gate

The full-envelope classical baseline still misses the target: pad acquisition
under persistent disturbances and sensor bias needs work. Validate a disturbance
estimate and trajectory diagnostics before tuning residual rewards or scheduling
another multi-million-step run. The current strictly negative nonterminal mission
cost is for baseline diagnostics; its discounted learning behavior has not been
validated. No V29 training script or trained weights are shipped in this milestone.
